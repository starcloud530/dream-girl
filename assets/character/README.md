# Character assets (demo)

## Authorization scope

Portraits here are **demo placeholders** for the open-source MVP only
(local bring-up, screenshots, CI/docs illustrations).

They are **not** a commercial likeness license. Do **not** ship them as the
face of a paid product, public SaaS, or marketing site without your own rights.

## Production

Replace every sample image with assets you own or have licensed before
production / commercial use. Keep filenames expected by the stack, or update
config paths accordingly.

Default layout uses `xiaoya-v1-sit.jpg` (2:3 body) + a top 1:1 crop for the
face-stack MSE path. `install` / `start` may rsync this directory into
`app/assets`.
